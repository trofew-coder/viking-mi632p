## Запись от 2026-11-27 (3)

**Дата и время:** 2026-11-27 (Европа/Москва) — финальный этап: обновление web_control.py, прошивка, тест

**Задача:** Устранение CH340-перезагрузки, обновление main.cpp, тестирование

**Изменённые файлы:**
- `firmware/mega2560/src/main.cpp` — добавлена команда ESC, перераспределены пины
- `firmware/remote_d1mini/src/main.cpp` — неблокирующий HTTP (throttle 200ms)
- `pi/web_control.py` — исправлен `blade_on` конфликт (флаг `_bladeOn`), добавлен `/api/esc`
- `docs/PINOUT.md` — обновлена распиновка
- `docs/PROTOCOL.md` — добавлена команда ESC

**Суть изменений и статус:**

### 1. Arduino Mega (main.cpp) — полная перепишка
**Проблема:** `String rxBuffer = ""` фрагментирует память (2 КБ ОЗУ). CH340 перезагружается при открытии порта (DTR).

**Решение:**
- `String rxBuffer` → `char rxBuffer[64]` с ручным управлением размером
- `processCommand(String)` → `processCommand(const char*)` с `strchr()`/`strtok()`
- BLDC ESC через Servo library (1000–2000 мкс, 1500 = нейтраль)
- ESC в нейтраль при старте и при аварии — безопасное состояние
- HEARTBEAT_TIMEOUT: 300 → 1000 мс
- Пины: ESC(8/9), сервы(11/12), реле(47/48), нож(49) — **без конфликтов**

### 2. D1 mini — неблокирующий HTTP
**Проблема:** `sendState()` блокирует loop на 1.5+ сек, импульсы энкодера теряются.

**Решение:**
- `trySendState()` с throttle 200 мс
- Энкодер обрабатывается каждый loop — импульсы не теряются

### 3. web_control.py — исправление blade_on
**Проблема:** `self.blade_on` — одновременно метод и флаг (перезаписывается).

**Решение:**
- Флаг → `self._bladeOn` (приватный)
- Метод `set_blade(on)` устанавливает флаг + шлёт команду
- API `/api/esc` для ручной калибровки ESC из веб-интерфейса
- **ВАЖНО:** Добавлен `time.sleep(2.2)` после открытия Serial для калибровки CH340 (загрузчик Arduino)
- **ВАЖНО:** Порт `/dev/serial/by-path/...` вместо `/dev/ttyUSB0` для стабильности

### 4. FIX: CH340 перезагрузка от DTR
**Проблема:** `stty -F /dev/ttyUSB0 115200` дергает DTR → Mega перезагружается.

**Решение:**
- `dsrdtr=False` в `serial.Serial()` для тестов (не сбрасывать Mega при чтении)
- `time.sleep(2.2)` после открытия порта — ждать загрузчика Arduino (перезагрузка при подключении)
- НЕ использовать `stty` + `echo` для проверки UART
- Вместо этого: Python pyserial `serial.Serial(port, baud, dsrdtr=False)`

### 5. Новые пины Mega 2560 (конфликтов нет)
| Назначение | Пин |
|---|---|
| ESC левый (BLDC) | 8 (Servo) |
| ESC правый (BLDC) | 9 (Servo) |
| Серва 1 | 11 (Servo) |
| Серва 2 | 12 (Servo) |
| Реле 1 | 47 |
| Реле 2 | 48 |
| Нож (BLADE) | 49 |
| Бампер перед/зад | 30/31 |
| Наклон L/R | 32/33 |
| LCD I2C | 20/21 |

### 6. Команда ESC (новая)
**Pi → Mega:** `ESC;US_L;US_R` (микросекунды 1000–2000)
**Mega → Pi:** `ACK;ESC;US_L;US_R`

**Суть изменений и статус:**

### 1. Arduino Mega (main.cpp) — полная перепишка
**Проблема:** `String rxBuffer = ""` в loop при быстрых командах фрагментирует память. На Mega 2560 всего 2 КБ ОЗУ → со временем висяк.

**Решение:**
- Убран `String` → чистые C-строки `char rxBuffer[64]` с ручным управлением размером
- `processCommand()` принимает `const char*`, парсинг через `strchr()`/`strtok()` — без временных `substring`
- Переход на BLDC ESC через Servo library (1000–2000 мкс)
- ESC в нейтраль (1500 мкс) при старте и при аварии — безопасное состояние
- HEARTBEAT_TIMEOUT увеличен с 300 до 1000 мс
- Пины перераспределены — **конфликты серв/реле убраны**: ESC(8/9), сервы(11/12), реле(47/48), нож(49)
- 2 сек задержка при старте для калибровки ESC

### 2. D1 mini — неблокирующий HTTP
**Проблема:** `sendState()` блокирует loop на 1.5+ секунды (http.setTimeout(1500)). Пока POST висит, импульсы энкодера теряются.

**Решение:**
- `trySendState()` с throttle 200 мс — не блокирует loop
- Если POST не успел — игнорируем, отправим в следующей итерации
- Энкодер обрабатывается каждый loop, импульсы не теряются

### 3. web_control.py — исправление blade_on
**Проблема:** `blade_on` — одновременно метод и флаг `self.blade_on`. После первого вызова `blade_off()` метод перезаписывается в `False`.

**Решение:**
- Флаг переименован в `self._bladeOn` (приватный)
- Метод `set_blade(on)` устанавливает флаг + шлёт команду
- Методы `blade_on()` / `blade_off()` вызывают `set_blade()`
- API `/api/esc` для ручной калибровки ESC из веб-интерфейса
- В HTML добавлена панель ESC калибровки (два числовых поля + кнопка «Применить»)
