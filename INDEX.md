## 2. Единый файл обмена сообщениями

Все сообщения команды пишутся в **единый файл обмена**:

📄 **`docs/TEAM_LOG.md`**

Правила записи:
1. Новая запись — **сверху** файла.
2. Сначала **представься** (имя участника / роль).
3. Поставь **дату и время**.
4. Затем пиши текст сообщения.

Формат:
```
[Участник] | 2026-11-27 09:00
Текст сообщения...
```

Это избавляет владельца проекта от ручного копи-паста между чатами.

## 5. Ветки и коммиты

- Работа ведётся в отдельных **ветках** (feature-ветки), не прямо в `main`.
- Сообщения коммитов — **понятные и описательные** (что и зачем изменено).
- Финальный push в GitHub выполняется **после** согласования в Bitrix24 и заливки на платы.
- Пуш делает владелец проекта или VS Code Copilot / GigaCode по SSH.

---

## 6. Порядок версионирования

- Версия поднимается при каждом затронутом модуле или прошивке.
- Каждое изменение фиксируется в `docs/CHANGELOG.md`.
- При значимых выпусках — ставится **тег** (например `v0.3.0`).
- Версия указывается в формате `MAJOR.MINOR.PATCH`.

---

## 7. Чек-лист перед заливкой на платы

Перед любой заливкой (Pi 5 / Mega 2560 / D1 mini) обязательно:

- [ ] Сверить пины с `docs/PINOUT.md`.
- [ ] Сверить протокол с `docs/PROTOCOL.md`.
- [ ] Убедиться, что код синхронен с документацией.
- [ ] Согласовать решение в Bitrix24.
- [ ] Сделать бэкап текущей прошивки.
- [ ] Заливает **один** (VS Code Copilot через SSH / GigaCode).
- [ ] Записать изменение в `docs/CHANGELOG.md` и `docs/TEAM_LOG.md`.

---

## 8. Золотые правила (кодекс)

1. **Единый источник истины — GitHub**; зеркало на Диске — актуальная синхронизированная копия.
2. Перед написанием кода — **сверься с базой** (`PINOUT.md`, `PROTOCOL.md`, исходники).
3. **Не плоди дубликаты файлов** — используй каталог раздела 3.
4. **Описывай изменения** в журнале и в `TEAM_LOG.md` — обязательно.
5. **Раньше предупреждай** о конфликтах пинов или протокола, чем код уйдёт на заливку.
6. **Заливает один** — без права нагромождать параллельные заливки.
7. **Секреты не публикуем** — пароли/доступ только в `MEMORY.md`, не в чатах.
8. **Код и документация всегда синхронны** — рассинхрон блокирует заливку.
