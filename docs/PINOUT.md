# Пины Mega 2560 — версия от 27.11.2026

**Изменения:** Переход на BLDC ESC, все конфликты устранены, каждый пин используется только для одного устройства.

## Силовая часть

| Назначение | Пин | Тип | Примечание |
|---|---|---|---|
| ESC левый (BLDC) | 8 | Servo library | 1000-2000 мкс, 1500 = нейтраль |
| ESC правый (BLDC) | 9 | Servo library | 1000-2000 мкс, 1500 = нейтраль |
| Нож (BLADE) | 49 | DIGITAL OUTPUT | Силовой ключ/реле |
| Реле 1 | 47 | DIGITAL OUTPUT | |
| Реле 2 | 48 | DIGITAL OUTPUT | |

## Сервы

| Назначение | Пин | Тип | Примечание |
|---|---|---|---|
| Серва 1 | 11 | Servo library | 0-180° |
| Серва 2 | 12 | Servo library | 0-180° |

## ⚠️ Важные примечания

1. **Пины 2 и 3 НЕ используются** — были зарезервированы для PWM моторов (L298N), сейчас отключены.
2. **Пины 18-21 НЕ используются** — были в плане для энкодеров колёс, конфликтуют с I2C. Ждать одометрии.
3. **Пин 53 НЕ используется** — был для сервы 2, перенесён на пин 12.
4. **Безопасное состояние при старте:** ESC=1500 (нейтраль), сервы=90°, все реле=OFF, нож=OFF.
5. **Безопасное состояние при аварии (SAFE):** ESC=1500 (нейтраль), все = OFF.
