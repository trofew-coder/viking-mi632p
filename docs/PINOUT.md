# Пины Mega 2560 — версия от 27.11.2026 (Serial3)

**Изменения:** 
- Переход на BLDC ESC через Timer1 direct (пины 11/12)
- UART переведён на `Serial3` (пины 14 TX3 / 15 RX3) — `Serial` (0/1) неисправен, RX0 выгорел
- Все конфликты устранены, каждый пин используется только для одного устройства

| Назначение | Пин | Тип | Примечание |

## ⚠️ Важные примечания

1. **Пины 2 и 3 НЕ используются** — были зарезервированы для PWM моторов (L298N), сейчас отключены.
2. **Пины 18-21 НЕ используются** — были в плане для энкодеров колёс, конфликтуют с I2C. Ждать одометрии.
3. **Пин 53 НЕ используется** — был для сервы 2, перенесён на пин 12.
4. **Безопасное состояние при старте:** ESC=1500 (нейтраль), сервы=90°, все реле=OFF, нож=OFF.
5. **Безопасное состояние при аварии (SAFE):** ESC=1500 (нейтраль), все = OFF.
