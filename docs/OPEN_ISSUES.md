- [x] Пины серв/реле конфликтуют (8/53) → перераспределены (ESC 11/12, сервы 4/5, реле 47/48/49)
- [x] String fragmentation в rxBuffer → `char rxBuffer[64]` + `strchr()`/`atoi()`

- [x] UART на неисправном Serial (пины 0/1) → переход на Serial3 (пины 14/15)
- [x] PL2303 USB-UART мост не справляется → переход на прямой `/dev/ttyAMA0`
