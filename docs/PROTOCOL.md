# Протокол Pi ↔ Mega (115200, текст, поля через «;»)

**Версия:** 3.0 (от 27.11.2026)
**Фреймворк:** Arduino Mega 2560 + Raspberry Pi 5
**Связь:** `/dev/ttyAMA0` (GPIO 14/15), 115200 baud, 8N1
**Формат фрейма:** `$CMD;ARGS*CS\n` — старт `$`, контрольная сумма XOR `*XX`

---

## Формат фрейма

```
$CMD;ARGS*CS\n
```

| Часть | Описание |
|---|---|
| `$` | Стартовый маркер — игнорирует мусор на линии |
| `CMD;ARGS` | Команда с аргументами через `;` |
| `*` | Разделитель контрольной суммы |
| `CS` | XOR всех байтов между `$` и `*` (2 hex-символа, регистронезависимо) |
| `\n` | Завершение кадра |

**Примеры:**
```
$HB*0A\n
$DRV;100;-50*2F\n
$ESC;1500;1500*1D\n
```

**Контрольная сумма XOR:**
```
XOR всех байтов «CMD;ARGS» = CS
$HB → 'H' ^ 'B' = 0x08 → $HB*08\n
$DRV;100;-50 → 'D'^'R'^'V'^';'... = 0x2F → $DRV;100;-50*2F\n
```

**Валидация на Mega:**
- Если не начинается с `$` → игнорировать (мусор/наводки)
- Если XOR не совпадает → игнорировать (битый пакет)
- Только после проверки `*CS` → выполнять

## Pi → Mega (команды)

| Команда | Описание | Формат | Ответ |
|---|---|---|---|
| HB | Heartbeat (каждые 250 мс) | `$HB*0A\n` | `ACK;HB` |
| DRV | Скорость моторов | `$DRV;l;r*CS\n` | `ACK;DRV` |
| BLD | Нож вкл/выкл | `$BLD;0/1*CS\n` | `ACK;BLD` |
| S1 | Серва 1 угол | `$S1;0-180*CS\n` | `ACK;S1;N` |
| S2 | Серва 2 угол | `$S2;0-180*CS\n` | `ACK;S2;N` |
| R1 | Реле 1 | `$R1;0/1*CS\n` | `ACK;R1;N` |
| R2 | Реле 2 | `$R2;0/1*CS\n` | `ACK;R2;N` |
| TIME | Синхронизация времени | `$TIME;HH;MM*CS\n` | `ACK;TIME;HH:MM` |
| ESC | Калибровка ESC | `$ESC;US_L;US_R*CS\n` | `ACK;ESC;US_L;US_R` |
| ROT | Состояние пульта энкодер | `$ROT;n*CS\n` | — |
| BTN | Кнопка пульта клик | `$BTN*0C\n` | — |
| RST | Сброс пульта длинный клик | `$RST*0B\n` | — |

### Параметры DRV (скорости моторов)
- Диапазон: **-255 .. 255**
- Отрицательное = назад, положительное = вперёд, 0 = стоп
- BLDC ESC конвертирует скорость в микросекунды:
  - 0 → 1500 мкс (нейтраль)
  - +255 → 2000 мкс (макс вперёд)
  - -255 → 1000 мкс (макс назад)

### Параметры ESC (ручная калибровка)
- Диапазон: **1000 .. 2000** микросекунды
- 1000 = максимальная скорость назад
- 1500 = нейтраль (стоп)
- 2000 = максимальная скорость вперёд

### Параметры пульта (D1 mini)
- ROT — поворот энкодера, n = значение (может быть отрицательным)
- BTN — короткое нажатие кнопки на пульте
- RST — долгое нажатие кнопки на пульте (сброс rot в 0)

## Mega → Pi (ответы)

| Сообщение | Описание | Формат |
|---|---|---|
| ACK | Подтверждение команды | `ACK;CMD;[данные]` |
| SENS | Телеметрия (каждые 5000 мс) | `SENS;bF;bR;tL;tR;mV` |
| SAFE | Аварийный стоп | `SAFE;reason` |
| ERR | Ошибка команды | `ERR;code` |
| BOOT | Приветствие (при старте) | `ACK;BOOT BLDC` |

### SENS — расшифровка
| Поле | Описание | Формат |
|---|---|---|
| bF | Бампер перед (1 = сработан) | 0/1 |
| bR | Бампер зад (1 = сработан) | 0/1 |
| tL | Наклон лев (1 = наклонён) | 0/1 |
| tR | Наклон прав (1 = наклонён) | 0/1 |
| mV | Напряжение батареи | милливольты (29500 = 29.5V) |

### SAFE — причины
| Причина | Описание |
|---|---|
| TILT | Наклон робота (опасность опрокидывания) |
| HEARTBEAT_LOST | Потеря связи с Pi (>2000 мс) |

## D1 mini → Pi (HTTP API)

### POST /remote
Отправка состояния пульта. JSON в теле запроса.

**Формат запроса:**
```json
{"rot": 42, "event": "ROTATE"}
```

**Допустимые event:**
- `ROTATE` — поворот энкодера (rot = значение)
- `CLICK` — короткое нажатие (rot = текущее значение)
- `LONG_PRESS` — долгое нажатие (rot = 0)

### GET /remote/state
Получение состояния пульта.

**Ответ:**
```json
{
  "rot": 42,
  "event": "ROTATE",
  "clicks": 3,
  "last_at": 1732699200.5,
  "age": 0.5
}
```
- `rot` — последнее значение энкодера
- `event` — последнее событие
- `clicks` — количество кликов
- `last_at` — timestamp последнего ответа (Unix epoch)
- `age` — время без ответа в секундах (отрицательное = пульт ещё не отвечал)

## Особенности

1. **Прямой UART `/dev/ttyAMA0`** (GPIO 14 TX / GPIO 15 RX), отключена консоль `serial-getty`.
   - Mega TX3 (5В) → делитель 1к+2к → Pi GPIO15 (RX, 3.3В)
   - Pi GPIO14 (TX, 3.3В) → Mega RX3 (5В, безопасно)
   - GND → GND

2. **Защита от помех:** `$` и `*CS` — мусорные пакеты от наводок моторов отбрасываются.

3. **Heartbeat обязателен:** каждые **250 мс**. Если Pi не шлёт HB > **2000 мс**, Mega → `SAFE;HEARTBEAT_LOST`.

4. **TILT мгновенный:** если любой датчик наклона активен, Mega сразу шлёт `SAFE;TILT` и стоп.

5. **Таймаут чтения порта:** 10–50 мс, не блокирует HB.

6. **Буфер UART:** `char rxBuffer[64]`, max команда 63 символа.
